# Contributing

Thanks for helping make Compicker sharper.

This skill should stay focused on one job: compare visual or UI alternatives in the real product, help choose a winner, then cleanly remove the temporary picker.

## Principles

- Keep the workflow small, practical, and product-aware.
- Preserve the distinction between temporary picker code and permanent product code.
- Prefer accessible controls and browser verification.
- Avoid project-specific implementation details in the skill itself.
- Add examples only when they clarify a reusable pattern.

## Pull Requests

Please include:

- what behavior or guidance changed
- why the change belongs in the durable skill
- any examples or screenshots that explain the change

If you add generated or designed assets, keep them under `assets/` and avoid brand names, watermarks, or license-unclear source material.
